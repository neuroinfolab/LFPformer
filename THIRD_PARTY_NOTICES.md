# Third-party software and data

The repository contains original project research sources collected from the Alphabrain_staging and GCP training snapshots, with original and release hashes recorded in reproducibility/source_manifest.json. A license grant for those sources has not been supplied; select an approved project license before redistribution.

Runtime dependencies include PyTorch/torchaudio, Hugging Face Transformers, NumPy, SciPy, scikit-learn, pandas, the IBL ONE/ibllib/iblatlas/neuropixel tools, and the AllenSDK. Each retains its own license. Installing dependencies does not transfer their licenses to this project.

Model initialization can use facebook/wav2vec2-base. Its model card and applicable terms govern those weights. Dataset access and redistribution remain subject to the IBL, Allen Institute and NeuroNexus source terms. No raw recordings, authentication files, service-account keys or model checkpoint binaries are included in this release.
